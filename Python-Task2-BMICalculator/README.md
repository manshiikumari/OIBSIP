\# BMI Calculator



\## Description

A simple Python command-line BMI Calculator that calculates Body Mass Index based on the user's weight and height.



\## Features

\- Takes weight in kilograms as input

\- Takes height in meters as input

\- Calculates BMI

\- Displays BMI rounded to 2 decimal places

\- Classifies BMI as Underweight, Normal, Overweight, or Obese

\- Validates non-numeric input

\- Rejects negative and zero values



\## Formula



BMI = weight / (height²)
