\# Weather App



\## Description

A simple Python command-line Weather App that retrieves current weather information for a city using the OpenWeatherMap API.



\## Features

\- Accepts a city name from the user

\- Retrieves current weather information

\- Displays temperature in Celsius

\- Displays humidity

\- Displays weather condition

\- Displays wind speed

\- Handles invalid city names

\- Handles invalid API keys

\- Handles network errors and request timeouts



\## Technologies Used

\- Python

\- Requests

\- OpenWeatherMap API
