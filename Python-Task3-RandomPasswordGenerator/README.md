\# Random Password Generator



\## Description

A Python command-line tool that generates random passwords based on the user's chosen length and character types.



\## Features

\- Minimum password length of 8 characters

\- Supports uppercase letters

\- Supports lowercase letters

\- Supports numbers

\- Supports symbols

\- Requires at least 2 character types

\- Validates invalid input

\- Allows users to generate multiple passwords



\## Technologies Used

\- Python

\- random module

\- string module



\## How to Run



Open the terminal in the project folder and run:



```bash

python password\_generator.py
